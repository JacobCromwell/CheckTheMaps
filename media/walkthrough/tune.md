# Tune how strict it is

| Strictness | What gets flagged |
|---|---|
| **Lenient** (default) | Only prompts that are likely to produce the wrong thing or a long, wandering answer |
| **Balanced** | Prompts that leave out something important for their size |
| **Strict** | Any prompt that skips a MAPS element its size needs. Good while you're learning |

Other settings worth knowing:

- **Send passing prompts automatically.** Turn it off if you'd rather click **Send to Copilot** yourself.
- **Send in mode.** Send passing prompts in a specific chat mode, such as `agent`.
- **Daily check limit.** A safety cap on model checks per day (default 300).

Click the **MAPS** item in the status bar at any time for these options and today's numbers.
