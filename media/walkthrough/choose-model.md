# Pick the checker model

Checks use a small, cheap model, never the premium model you chat with.

By default, Check The MAPS uses **the cheapest model with a known price** from the models you have. A typical check costs a tiny fraction of an AI credit. It never switches to a premium model on its own: if no low-cost model is available, your prompt is simply sent on unchecked.

**Choose Checker Model** lists every model you can use, with an estimated cost per check, so you can pin a specific one.

The first check asks you to allow Check The MAPS to use the model. That's a one-time VS Code prompt.
